# Рубеж Эха (Echo Threshold)

Браузерная Tower Defense, реализованная по мастер-промпту `Tower_Defense_Master_Prompt_RU.txt`.
Древняя сеть маяков защищает архипелаг от существ из разлома.

## Возможности

- **5 карт** с уникальными маршрутами, механиками окружения и кривой сложности; ≥10 волн на карту, элитные угрозы и босс на финальной волне.
- **12 типов башен**, у каждой базовый уровень + ровно два улучшения (I и II). Характеристики буквально соответствуют спецификации ТЗ (раздел 9).
- **Две валюты**: постоянные «хроники» аккаунта (магазин разблокировок) и временные боевые «кредиты» (строительство/улучшения).
- **Магазин разблокировок**: 7 платных башен (сумма цен 1550 ⟡), стартовый запас 200 ⟡, награды за первые прохождения 210/240/270/300/330 ⟡. Повторные победы дают +20/+10/+5 ⟡ (дальше 0), счётчики хранятся отдельно по каждой карте; награда начисляется один раз после фактической победы.
- **Боевой набор**: от 1 до 5 различных типов башен (лимит типов, не экземпляров); строить можно только башни из набора.
- **Скорость симуляции**: ровно три режима — 1×, 1.5×, 2.5×; пауза полностью останавливает симуляцию.
- **Сохранение прогресса** в localStorage (v2 с миграцией v1), устойчивое к повреждённым/устаревшим данным.
- Экраны: главное меню, выбор карт, коллекция/магазин, подготовка набора, бой, панель выбранной башни, результаты, настройки.
- Управление: мышь, клавиатура (Пробел — волна, P — пауза) и сенсорный экран.

## Запуск

Требуется Node.js ≥ 18.

```bash
npm install        # устанавливает только jsdom (для тестов)
npm start          # npx serve -l 3000 .
```

Откройте http://localhost:3000 в браузере. Сервер приложений, платные API и ключи не требуются.

Альтернативный способ без npm: любой статический файловый сервер в корне проекта
(например, `python3 -m http.server 3000`).

## Тесты

```bash
npm test
```

Включают:

1. **Юнит-тесты данных и экономики** (`tests/run.js`): согласованность 12 башен, цен разблокировок (Σ=1550), наград карт, лимитов набора, покупки/идемпотентности наград, санитайзера сохранений.
2. **DOM-интеграционные тесты в jsdom** (`tests/dom.js`): загрузка игры, все экраны, набор 1–5 типов, запрет строительства вне набора, цикл скоростей 1→1.5→2.5, пауза, вызов волны, магазин (списание ровно один раз), победа/награды/разблокировка карты, персистентность между «перезагрузками», обработка повреждённого сохранения, отсутствие ошибок консоли.
3. **Проходимость кампании** (`tools/balance.js`): headless-симуляция всех 5 карт — 5/5 побед эталонными стратегиями.
4. **Проверки отрицательных сценариев** (`tools/probe.js`): без башен — поражение, одна башня — поражение, только крио против воздуха — прорывы, полный набор L2 — победа.

## Структура проекта

```
index.html            — каркас интерфейса (экраны, HUD, canvas)
css/style.css         — визуальный стиль, адаптивность (десктоп/мобильные)
data/towers.js        — 12 башен: цены, уровни I/II, характеристики (ТЗ §9)
data/enemies.js       — враги, элиты, боссы, брони/сопротивления (ТЗ §10)
data/maps.js          — 5 карт: маршруты, платформы, волны, награды (ТЗ §7-8)
engine/simulation.js  — чистая игровая модель: движение, цели, снаряды, эффекты, экономика боя
engine/render.js      — процедурная отрисовка на Canvas
engine/save.js        — хроники, разблокировки, награды, миграция/санитайз сохранений
engine/audio.js       — WebAudio-синтез звуков (без внешних файлов)
js/game.js            — оркестратор: экраны, ввод, игровой цикл, скорости, пауза
ui/hud.js             — панель HUD, панель башни, магазин, подготовка набора
tools/balance.js      — headless-проверка проходимости 5 карт
tools/probe.js        — негативные сценарии баланса
tests/run.js          — точка входа тестов (unit + jsdom + tools)
tests/dom.js          — интеграционные DOM-тесты в jsdom
Tower_Defense_Master_Prompt_RU.txt — техническое задание (мастер-промпт)
```

## Статус проверок (честно)

- ✅ Все автотесты проходят: unit + jsdom-DOM-сценарии + проходимость 5/5 + негативные пробы.
- ✅ Интерфейс, экономика хроник, покупки, награды, набор 1–5, скорости 1×/1.5×/2.5×, пауза, сохранения проверены в jsdom (полный DOM + исполнение скриптов, ноль ошибок консоли).
- ⚠️ Финальная визуальная проверка в реальном браузере (внешний вид canvas, звук, тач-жесты) выполняется вручную: `npm start` → открыть http://localhost:3000.
